# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub's private vulnerability reporting:
<https://github.com/nfdi4cat/voc4cat-tool/security/advisories/new>

Do not open a public issue for a vulnerability.
The maintainers acknowledge a report within 5 working days and keep you informed until it is resolved.

## Supported versions

Only the latest release on [PyPI](https://pypi.org/project/voc4cat/) receives security fixes.
A fix is published as a new release.
